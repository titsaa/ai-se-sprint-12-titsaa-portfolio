# Titsa'a Ndipowa's Portfolio

A responsive, single-page portfolio showcasing my projects, skills, and contact details as a full-stack MERN developer and TripleTen Software Engineering graduate.

**Live site:** _coming soon (Vercel preview link)_

## Stack

- React 19 + TypeScript
- Vite
- Plain CSS with BEM naming and CSS custom properties
- ESLint + Prettier
- GitHub Actions CI (build, lint, format check)
- Deployed on Vercel

## Features

- Content stored as strictly typed data in `src/data`
- Fixed header with a mobile menu toggle
- Projects grid with a "Show more" button
- Skills grouped by category
- Contact links with a downloadable resume
- Responsive layout from desktop to mobile

## Getting started

```bash
npm install
npm run dev
```

## Scripts

| Command                | Description                         |
| ---------------------- | ----------------------------------- |
| `npm run dev`          | Start the development server        |
| `npm run build`        | Type-check and build for production |
| `npm run lint`         | Run ESLint                          |
| `npm run format`       | Format all files with Prettier      |
| `npm run format:check` | Check formatting without writing    |
